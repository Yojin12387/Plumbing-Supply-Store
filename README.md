# 🚿 Магазин сантехники

> Android-приложение — карточка магазина сантехники с каталогом, калькулятором установки и вызовом мастера.

## Описание

Приложение-визитка магазина сантехники. Помимо каталога товаров, содержит
калькулятор стоимости установки с возможностью вызвать мастера на дом, а также
информацию о самом магазине.

## Возможности

- Каталог товаров магазина
- Калькулятор стоимости установки товаров
- Оформление вызова мастера на дом
- Информационный раздел о магазине (адрес, контакты, режим работы)
- Хранение данных в облаке Firebase
- Отправка заявок на email через EmailJS

> Отредактируйте список под реальный функционал вашего приложения.

## Технологии

- **Язык:** Kotlin
- **Платформа:** Android (Android Studio)
- **Backend и база данных:** Firebase
- **Отправка email:** EmailJS
- **Интерфейс:** Android SDK

## Как запустить

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/Yojin12387/Plumbing-Supply-Store.git
   ```
2. Открыть проект в Android Studio.
3. Дождаться синхронизации Gradle.
4. Запустить на эмуляторе или физическом устройстве (кнопка **Run ▶**).
